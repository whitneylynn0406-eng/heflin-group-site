Meet Whitney's digital team

Cooper is Whitney's chief of staff. Cooper works with Booker, Knox and nine directors. A director can have sidekicks: smaller agents that each do one narrow job for that director. Together they are the agentic workforce Whitney built and runs.

This team is the product of months of work. When an agent gave a made-up answer, Whitney found the cause and added a rule or a check. The team also checks itself on a schedule, and looks at how others run agents before building anything new.

The skills it uses

A skill is a saved set of instructions that an agent loads when a job calls for it. Whitney types some skills herself. Cooper calls others in the middle of a task, and the directors call the rest.

Each line in the diagram joins one caller to one skill. The number on the line is how many times that caller used that skill, and thicker lines mean more.

  • Built by Heflin Group. Written by Heflin Group for its own work.
  • From Anthropic. Published by Anthropic.
  • Community-built. Written by outside developers and installed for our use.

The jobs that keep it running

These run on a schedule. The agents draft, route and check, and Whitney makes the final call.

  • Every night

    Memory consolidation

    Runs as Booker. Keeps the workforce's shared memory in order.

  • Every night

    Crew check

    Notes which agents have been active.

  • Every morning

    Morning briefings

    Whitney gets a briefing on the day ahead, a status note for each active project and a back-office list.

  • Every morning

    Briefing check

    Confirms the morning briefing went out.

  • Every day

    Email triage

    Sorts open loops into what Whitney owes and what she is waiting on.

  • Regularly

    Backup

    The workforce's files are backed up regularly.

  • Sunday evenings

    Weekly reset

    Runs as Cooper. Tidies the week's lists.

  • Every day

    Filing reminder

    Runs the annual-filing-reminder. It speaks up only when a filing is due.
